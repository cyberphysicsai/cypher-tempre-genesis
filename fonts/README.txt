Cypher Tempre typography assets
==============================

The unmodified Orbitron, Courier Prime and Manrope fonts are bundled locally. The application makes no
font requests to Google or another third party at runtime.

Cyber mode uses Orbitron throughout the interface. Typewriter mode uses Courier
Prime. Clarity mode uses Manrope, with Courier Prime for aligned code and hashes.
Each mode covers chat, forms, menus, labels, ability controls and the auditor.
Font choice is independent of the Dark, Light and Matrix color modes.
